# CrossFit Trowbridge (CFT) website

Working repo for the [CrossFit Trowbridge](https://crossfit-trowbridge.com/) WordPress site.

## What lives here

| Path | Purpose |
|---|---|
| `themes/cfbath-Child-Theme/` | Active child theme (custom CSS + PHP overrides) |
| `HANDOFF.md` | Process, architecture, staging → live workflow |
| `docs/access-checklist.md` | Access inventory template (store secrets elsewhere) |

## Golden rule

**Make changes on staging first. Push to live only after review.**

Do not edit the live site directly unless it is a genuine emergency.
